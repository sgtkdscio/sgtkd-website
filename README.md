# SGTKD-SCIO Website

A responsive static website built for free hosting on Cloudflare Pages.

## Files
- `index.html` — website structure
- `styles.css` — design and responsive layout
- `script.js` — navigation and scroll animations

## Before launch
Replace:
- `YOUR-EMAIL-HERE` in `index.html`
- Training timetable `TIME TBC` entries
- Social media links
- Gallery placeholders with club photography

## Deploy
Push these files to the GitHub repository, then connect the repository to Cloudflare Pages.
